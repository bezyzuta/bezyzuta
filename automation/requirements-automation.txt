# Desktop automation: real OS-level mouse/keyboard + screen for native apps
# that have no API. Pixel/image based, so it's fragile to resolution changes.

# Used by the optional macro recorder (records real mouse/keyboard events so
# you can replay them). Not required for the helper APIs themselves.
